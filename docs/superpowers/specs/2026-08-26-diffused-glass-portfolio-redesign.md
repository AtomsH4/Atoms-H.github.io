# AtomsH4 清透弥散玻璃风格改版设计

## 背景

当前主页以复古像素游戏界面为主，使用粗黑边框、硬阴影、饱和粉青黄配色和玩家 HUD。视觉辨识度较高，但整体重量偏大，与本次参考图中的清透背景、弥散渐变和毛玻璃质感不一致。

本次改版将重做全站视觉系统，但保留现有单页信息架构、内容、链接和打字动画。设计方向采用已确认的 B「弥散玻璃」方案，并将首屏右侧视觉进一步调整为半透明毛玻璃像素矩阵。

## 已确认目标

1. 全站改为清透、弥散渐变、毛玻璃视觉风格。
2. 保留少量像素秩序感，但去掉粗边框、硬阴影和复古 HUD 的沉重感。
3. 删除右侧像素头像和 `PLAYER DATA` 状态卡。
4. 首屏右侧改为抽象毛玻璃像素矩阵。
5. 使用淡蓝、薰衣草紫和少量粉色作为主要弥散光色。
6. 保留现有导航、主页内容区块、项目资料、外链和英文名句。
7. 保留名句打字循环及减少动态效果支持。
8. 不引入框架、第三方字体、外部 CDN 或新的运行时依赖。

## 视觉系统

### 背景

页面底色使用接近白色的冷灰蓝。全页通过多个大尺寸、低对比度的径向渐变形成弥散光场，主要颜色为淡蓝、薰衣草紫和柔粉。渐变应有明显模糊和自然重叠，避免可见的圆形边界或高饱和色块。

背景不再使用现有的像素网格线。可增加极轻微的噪点或半透明光晕，但不得影响文字可读性。

### 玻璃层次

导航、首屏视觉容器、经历卡、技能卡、项目卡和联系区统一使用轻薄玻璃样式：

- 半透明白色背景；
- `backdrop-filter` 模糊与轻度饱和；
- 近白色的细边框；
- 柔和的大范围阴影；
- 较大的圆角；
- 内部高光用于表现玻璃边缘。

卡片之间依靠透明度、阴影深度和间距建立层级，不再使用粗黑描边和硬偏移阴影。

### 排版与颜色

主文字使用深蓝灰，辅助文字使用中性灰紫。`AtomsH4` 主标题可使用深色到紫色的低对比渐变文字，避免现有高饱和粉色大标题。

保留系统无衬线字体作为主要字体，名句继续使用现有等宽字体。导航和标签可以保留少量等宽字，以延续开发者身份，但不再全站大写或使用过重字重。

## 首屏设计

### 左侧内容

首屏继续保留：

- `AtomsH4` 主标题；
- 当前英文名句；
- 名句打字循环；
- 项目入口按钮；
- GitHub 按钮。

原有 `KEEP CODING`、`KEEP PLAYING` 像素徽章改为更轻的小型玻璃标签，或合并为一条简短的身份标签。按钮改为圆角胶囊形：主按钮为深蓝紫色实底，次按钮为透明玻璃底。

名句容器保持固定宽度边界和稳定高度。现有零宽光标实现继续保留，避免打字过程中因换行发生布局抖动。

### 右侧毛玻璃像素矩阵

删除头像、角色等级、经验条、状态栏和 `PLAYER DATA` 标题。

右侧改为 4×5 或 5×5 的抽象玻璃像素矩阵：

- 每个单元为半透明圆角方块；
- 方块以白色透明玻璃为主，不直接使用高饱和硬渐变；
- 蓝紫粉弥散光放置在矩阵下层，通过透明方块显现；
- 使用低对比细边框、内部高光、轻柔阴影和背景模糊表现玻璃厚度；
- 外围单元适当降低透明度，避免完整规则网格过于生硬；
- 整体允许轻微旋转或错位，但保持视觉重心稳定；
- 不使用图片或 SVG，优先用语义中性的 HTML 元素和 CSS 完成。

矩阵只作为装饰，使用 `aria-hidden="true"`，不进入键盘焦点和辅助技术阅读顺序。

## 内容区块

### 经历、技能与项目

现有 Quest、Skill、Project 内容和链接保持不变。结构继续使用响应式网格，但视觉上统一为玻璃卡片：

- 卡片编号或类型作为小号灰紫标签；
- 标题使用深蓝灰；
- 描述降低对比度；
- 技能标签改为半透明胶囊；
- 项目链接使用简洁文本箭头或圆角按钮；
- hover 时只做轻微上浮、边缘高光或阴影变化，不做像素式位移。

### 联系区

联系区保持原有内容与链接，但改为较大的玻璃面板，可在面板下方加入淡紫或淡蓝弥散光，形成页面收尾焦点。

## 动效

保留现有名句打字动画。新增动效应克制：

- 玻璃卡片 hover 轻微上浮；
- 毛玻璃矩阵保持静止，只有下层光晕执行非常缓慢的小幅移动；
- 不做持续旋转、强弹性或大幅视差；
- `prefers-reduced-motion: reduce` 下关闭新增漂浮和过渡动效，并继续直接显示完整名句。

## 响应式设计

- 桌面端首屏保持左右双栏，右侧矩阵占据约 40%–45% 宽度。
- `860px` 以下切换为单栏，矩阵位于文字内容之后。
- 小屏幕上的矩阵缩小单元尺寸并减少间距，不产生横向滚动。
- 导航允许折行或缩短间距，保持玻璃背景与可点击区域。
- 内容卡片从多列平滑降为单列。
- 不隐藏关键文字、项目链接或联系入口。

## 可访问性与兼容性

- 保持现有语义结构、标题层级和导航标签。
- 透明背景上的正文对比度必须足够，不能依赖背景模糊维持可读性。
- 对不支持 `backdrop-filter` 的浏览器提供更高不透明度的白色背景作为回退。
- 所有交互保持清晰的键盘焦点样式。
- 装饰性矩阵和光晕不进入辅助技术阅读顺序。

## 实现范围

本次预计修改：

- `index.html`：移除玩家 HUD 和头像结构，加入装饰矩阵结构，必要时调整标签文本与样式版本号；
- `styles.css`：重建全站视觉令牌、背景、导航、首屏、卡片、按钮、矩阵、响应式与减少动态效果样式；
- `scripts/verify-site.js`：更新结构和样式契约，删除头像与 HUD 断言，增加玻璃矩阵、玻璃样式和响应式断言；
- `script.js`：保持不变，继续使用现有打字循环实现。

不修改项目内容数据、外链、部署方式、Jekyll 配置或站点路由。不新增图片资源，不复用参考图中的品牌、文字或具体图形。

## 验证

定向验证覆盖：

1. 页面不再包含头像、`PLAYER DATA`、等级、经验条和状态栏。
2. 首屏存在装饰性玻璃像素矩阵，并正确隐藏于辅助技术。
3. 现有标题、名句、打字动画、主要按钮、内容区块和外链仍存在。
4. CSS 包含玻璃回退背景、`backdrop-filter`、弥散渐变、柔和阴影和新响应式规则。
5. `prefers-reduced-motion` 继续关闭相关动画。
6. 运行 `node --check script.js`、`node scripts/verify-site.js` 和 `git diff --check`。
7. 这是静态单页视觉重构，不需要运行与仓库无关的全局测试套件。
