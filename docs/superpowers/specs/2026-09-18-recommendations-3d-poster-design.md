# 3D 海报风推荐页设计

**状态：** 已确认，待用户审查
**日期：** 2026-09-18

## 1. 目标

为现有 Astro 博客增加独立的 `/recommendations/` 推荐页，并在首页展示近期精选。推荐内容覆盖音乐、书籍以及统一归类的影视与动画；页面使用白底黑字的编辑海报风，以可拖动旋转的 3D CD 和立体书作为主视觉。

体验参考来自 Ravi Klaassens 的 A24 概念设计：实体唱片横向铺陈、当前作品信息与实物联动、衬线标题和大面积留白。参考只用于建立视觉方向，不复制其品牌标志、排版内容或素材。

本期目标包括：

1. 建立可长期维护的推荐内容集合。
2. 提供单画布、多物体的 3D 海报舞台。
3. 让分类与 3D 外观低耦合，未来能以有限改动增加新的表现载体。
4. 在 WebGL 不可用、资源失败和减少动态效果等环境下提供完整降级体验。
5. 仅使用能够确认具有合法再利用依据的封面图片，并保存来源与许可信息。

## 2. 非目标

- 不实现书籍开合、逐页翻动或内部正文预览。
- 不提供自由镜头、缩放、物理碰撞或持续自动旋转。
- 不建设后台 CMS、通用插件系统或任意模型编辑器。
- 不接入音乐播放、视频播放、第三方评分或用户评分。
- 不自动抓取搜索结果图片，也不将“公开可见”等同于允许转载。
- 不把整个博客重做为黑白海报主题。

## 3. 现有项目实践与适用方式

当前站点使用 Astro 内容集合维护博客、随笔和项目，并使用 React 19 承担局部交互。页面由 `BaseLayout.astro` 组合共享页头、导航和页脚，内容卡片采用统一的三列响应式网格。

本功能沿用以下实践：

- 推荐条目作为新的 Astro 内容集合维护，构建阶段校验元数据。
- React 只承载需要浏览器运行的 3D 舞台和切换状态，文字内容由 Astro 输出静态 HTML。
- 继续复用站点页头、导航、页脚和 GitHub Pages 基础路径工具。
- 使用页面级专属布局隔离黑白海报主题，不改变现有页面的视觉效果。

现有 `EntryCard` 和 `EntryList` 偏向文章与项目摘要，缺少封面授权信息和 3D 表现语义，因此不复用它们承载推荐内容。推荐功能使用边界更窄的专属组件，避免扩张公共卡片 API。

## 4. 技术选型

### 4.1 推荐方案

使用以下 MIT 许可开源库：

- `three`：WebGL 渲染、几何体、纹理和物理材质。
- `@react-three/fiber`：以 React 组件组织 Three.js 场景，与项目已有 React 19 集成。
- `@react-three/drei`：使用 `PresentationControls`、`RoundedBox`、环境光和接触阴影等小型辅助组件。

Three.js 的 `MeshPhysicalMaterial` 支持 clearcoat、anisotropy 和 iridescence，适合表现 CD 的金属反光和虹彩；Drei 的 `PresentationControls` 支持受限拖动、触控与回弹。场景通过 Astro 客户端岛加载，不把 Three.js 运行时代码带入无关页面。

### 4.2 未选方案

1. **`<model-viewer>`：** 单个 GLB 展示、相机控制和海报懒加载很成熟，但不适合参考图所需的多物体交错构图、当前项重排和共享灯光舞台。
2. **Babylon.js：** PBR 和工具链完整，但对当前单一展示模块过重，也不如 React Three Fiber 贴合现有技术栈。
3. **OGL：** 体积较小，但控件、资源加载、物理材质与场景辅助需要自行搭建，增加实现和维护成本。

## 5. 信息架构

### 5.1 独立推荐页

新增 `/recommendations/`：

- 顶部复用站点品牌、导航和移动端菜单。
- 推荐导航项名称固定为“推荐”。
- 页面提供“全部 / 音乐 / 书籍 / 影视与动画”筛选。
- 当前作品的标题、类型、创作者、年份等资料显示在舞台左上区域。
- 中央舞台同时安排 3–5 个交错物体，当前作品最大，其他作品部分超出画面或退到背景。
- 舞台下方显示简短推荐语、外部详情链接以及封面来源信息。

### 5.2 首页精选

首页增加“近期推荐”区块：

- 展示三件 `featured: true` 的推荐内容。
- 使用同一套模型组件和缩减后的舞台组合，不复制几何体实现。
- 不在首页提供完整筛选和复杂切换，只允许轻微拖动旋转。
- 每件精选可链接到 `/recommendations/#<slug>`，进入完整页后将对应条目设为当前项。

## 6. 视觉设计

推荐页使用页面级黑白海报主题：

- 背景为略带暖色的白色，文字和线条使用近黑色。
- 作品标题和推荐引文使用系统衬线字体，导航和元数据使用系统无衬线字体。
- 元数据之间使用细横线分隔，形成编辑资料表质感。
- 不使用当前站点的青紫渐变、玻璃模糊、胶囊标签和大面积圆角卡片。
- 封面纹理是页面主要色彩来源；阴影只服务于物体的空间感。
- 推荐语使用大号衬线引文，但不伪造媒体评分或评论来源。

新增专属 `RecommendationLayout`，复用 `SiteHeader` 和 `SiteFooter`，在其 `body` 范围内覆盖背景、内容宽度和现有玻璃类的外观。这样可避免给共享 `BaseLayout` 增加仅服务单页的主题契约，也避免复制导航实现。

首页精选保留现有站点背景，将推荐区块处理为白底、黑色细边框的海报画幅，形成有意的视觉对比。

## 7. 内容模型与扩展边界

### 7.1 推荐条目

新增 `recommendations` 内容集合。每个 Markdown 条目包含：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `title` | 非空字符串 | 展示名称。 |
| `category` | `music \| book \| screen` | 语义分类和筛选依据。 |
| `presentation` | `disc \| book`，可选 | 覆盖分类的默认 3D 外观。 |
| `creator` | 非空字符串 | 歌手、作者、导演或主创。 |
| `year` | 整数 | 作品发行、出版或首播年份。 |
| `recommendDate` | 日期 | 推荐排序依据。 |
| `summary` | 非空字符串 | 一句推荐语。 |
| `cover` | 非空字符串 | 本地封面资源路径。 |
| `externalUrl` | HTTPS URL | 作品详情或权利方页面。 |
| `featured` | 布尔值，默认 `false` | 是否进入首页精选。 |
| `draft` | 布尔值，默认 `false` | 是否从生产构建隐藏。 |
| `coverAttribution` | 判别联合对象 | 见下方的封面来源规则。 |

Markdown 正文可填写较长推荐理由，但页面在正文为空时仍能完整工作。

`coverAttribution` 使用明确的判别联合，避免让生成封面伪造外部许可字段：

- 授权图片：`{ kind: 'licensed', sourceUrl, license, licenseUrl, credit }`，其中三个 URL 均为 HTTPS，其他字段为非空字符串。
- 原创排版封面：`{ kind: 'generated', credit }`，不填写虚假的来源或许可 URL。

### 7.2 分类与表现分离

分类配置集中维护以下信息：中文标签、创作者字段名称、默认 `presentation`。初始映射为：

- `music` → 音乐、音乐人、`disc`
- `book` → 书籍、作者、`book`
- `screen` → 影视与动画、导演/主创、`disc`

3D 模型注册表初始只暴露 `disc` 和 `book` 两个键。舞台根据规范化后的 `presentation` 查找模型组件，不根据 `category` 编写条件分支。

未来新增黑胶、磁带、游戏盒或海报时，需要新增模型组件并在注册表登记；新增分类时，需要新增分类配置和内容校验值。页面布局、筛选组件和舞台编排不随具体条目数量或名称变化。这里保持有限枚举和显式注册，不实现动态插件加载。

## 9. 封面素材规则

官方封面只有在来源页面明确提供公共领域、CC0、CC BY、CC BY-SA 或其他明确允许本项目使用的条款时才会被本地收录。每张图片必须同时保存可核验的来源、许可和署名元数据。

以下情况不能作为可用授权依据：

- 图片可以公开访问或下载。
- 搜索引擎显示了缩略图。
- 第三方资料站、网盘或社交媒体转载了图片。
- 通过外链或盗链而不是本地复制图片。
- 页面仅写“仅供宣传”但未说明第三方网站可转载。

如果某项作品没有找到能够确认自由使用的官方封面，则使用该作品标题、创作者和年份生成原创黑白排版封面。排版封面不得描摹原封面构图、标志或受保护的独特图形；以后替换为授权素材时只需更新内容字段和资源文件。

推荐页提供集中或逐项的图片来源信息，以满足署名和许可证链接要求。CC BY-SA 素材的衍生处理必须遵循相同方式共享条款。

## 10. 组件职责

- `RecommendationLayout.astro`：推荐页 HTML 骨架和页面级主题作用域；复用页头与页脚。
- `RecommendationPage.astro`：加载、排序、过滤内容并生成静态文字区域和 2D 降级列表。
- `RecommendationStage.tsx`：唯一的 WebGL 画布；维护当前项、舞台排列和交互状态。
- `DiscModel.tsx`：程序化构建 CD 正反面、外缘和内孔壁，并接受封面纹理。
- `BookModel.tsx`：程序化构建封面、书脊、封底和纸张块，并接受封面纹理。
- `recommendation-types.ts`：分类配置、表现类型、模型注册键和规范化逻辑。
- `RecommendationFallback.astro`：无 WebGL 或初始化失败时的二维封面横列。

页面和内容层只传递可序列化的推荐展示数据。模型组件不知道博客路由、筛选文案或首页状态；舞台不知道 Markdown 和内容集合的加载方式。

## 11. 交互规则

- 点击或聚焦非当前物体会将其设为当前项并重排舞台。
- 当前物体支持鼠标和单指拖动旋转，水平和垂直角度均有限制。
- 松手后物体回到该条目的预设海报角度，不产生无限惯性旋转。
- 不支持缩放、平移相机或把物体拖离构图。
- 上一项、下一项按钮和左右方向键可以循环切换当前筛选结果；结果少于两项时切换按钮禁用。
- 筛选后若当前条目不在结果中，选中筛选结果的第一项；空结果显示静态空状态。
- URL 锚点匹配有效 slug 时以该条目作为当前项；无效锚点回退到排序后的第一项。
- 点击外部详情链接在新标签页打开，并使用安全的 `rel` 属性。

移动端仍允许拖动当前物体旋转。作品切换依赖明确的按钮和点击相邻物体，不复用同一水平手势，避免与页面滚动或模型旋转争抢事件。

## 12. 3D 表现

### 12.1 CD

CD 使用多段简单几何体组合，形成带真实厚度的正面、背面、外缘和内孔壁。封面贴图应用在正面独立圆环上；基底使用具有金属度、较低粗糙度和适度虹彩的物理材质。环境光和矩形光源形成产品摄影式反射，接触阴影提供重量感。

### 12.2 书籍

书籍由封面、书脊、封底和纸张块组成。封面与封底具有轻微倒角，纸张使用偏暖白和较高粗糙度，书脊可展示简化标题纹理。书本保持闭合，不包含页面骨骼或翻页动画。

### 12.3 舞台

桌面宽度下同时展示 3–5 件物体；移动端将当前物体居中并只露出相邻物体边缘。物体位置和初始角度来自少量固定构图槽位，而不是为每条内容单独硬编码坐标。筛选或切换时把条目映射到槽位并进行短暂过渡。

## 13. 性能与资源策略

- 每个页面最多一个 WebGL Canvas。
- 使用按需渲染；静止时停止刷新，只在交互和过渡时请求帧。
- 设备像素比设定上限，避免高分屏成倍增加 GPU 成本。
- 几何体、材质和纹理缓存复用，并在卸载时释放非共享资源。
- 封面使用适当尺寸的 WebP；优先加载当前项与相邻项。
- 环境光贴图本地托管，不依赖运行时 CDN。
- 接触阴影尽量限制为静态帧或低分辨率，不启用高成本实时光线追踪效果。
- 首页舞台进入视口后再加载；加载前显示静态海报占位。
- 推荐页的文字、导航、筛选和降级列表不等待 3D 运行时。

## 14. 无障碍与错误处理

- Canvas 标记为装饰性区域；所有必要信息存在于 HTML 中。
- 筛选、上一项、下一项、当前项和外部链接具有可理解的可访问名称。
- 当前条目变化通过适度的状态文本表达，不让屏幕阅读器朗读连续旋转帧。
- 键盘可以完成分类筛选和作品切换；焦点样式保持高对比度。
- `prefers-reduced-motion` 下关闭漂浮和弹性回弹，状态切换使用即时或极短过渡。
- WebGL 不可用、初始化失败或上下文无法恢复时显示二维封面横列。
- 单张封面加载失败时显示由标题、创作者和年份生成的黑白排版封面。
- 3D 失败不阻止访问推荐语、图片来源或外部链接。

## 15. 验证策略

### 15.1 单元与组件测试

- 内容 schema 接受完整合法条目并拒绝未知字段、未知分类、未知表现类型、非 HTTPS 链接，以及授权图片缺失来源、许可或署名的条目；原创排版封面不要求外部许可 URL。
- 推荐排序、草稿过滤、首页精选和分类筛选结果正确。
- 分类默认表现与单条 `presentation` 覆盖正确，舞台无需按分类分支。
- URL 锚点解析、无效锚点回退和筛选后当前项重置正确。
- 键盘循环切换、单条结果时的按钮禁用以及减少动态效果分支正确。
- 封面错误和 WebGL 错误会进入二维降级状态。

Three.js 的几何细节不做脆弱的像素快照；测试稳定的组件契约、状态和可访问输出。

### 15.2 浏览器测试

- `/recommendations/` 可从主导航访问，GitHub Pages 子路径正确。
- 首页展示三件精选并能深链到对应推荐。
- 桌面端可以拖动当前 CD 和书籍旋转，松手后恢复预设角度。
- 移动端可以滚动页面、点击切换，并拖动当前物体而不误触导航。
- 分类筛选、左右按钮、键盘切换和外部链接正常。
- 禁用 WebGL 或模拟初始化失败时，二维内容仍可访问。

### 15.3 交付验证

运行与风险相匹配的内容测试、组件测试、站点端到端测试、Astro 类型检查和生产构建。由于新增内容集合、导航、首页和 3D 客户端岛跨越多个前端区域，需要运行完整项目现有测试，但不引入仓库之外的全局验证。

## 16. 验收标准

1. 主导航包含“推荐”，独立推荐页与 GitHub Pages 子路径均可访问。
2. 页面以白底黑字的海报风呈现，现有博客、随笔、项目与关于页视觉不受影响。
3. 音乐和影视动画使用可拖动旋转的 CD，书籍使用可拖动旋转的闭合立体书。
4. 页面使用单个 3D Canvas；物体不支持缩放、自由镜头、自动旋转或书籍翻页。
5. 首页展示三件精选内容，并能深链至推荐页对应条目。
6. 分类配置、内容分类和 3D 表现相互分离；新增注册过的表现类型不需要修改页面编排逻辑。
7. 所有正式封面均有可核验的自由使用依据和署名信息；无法确认许可的作品使用原创排版封面。
8. WebGL、封面或初始化失败时仍有完整的二维浏览与链接体验。
9. 键盘操作、减少动态效果和移动端交互满足设计规则。
10. 内容校验、测试、类型检查和生产构建全部通过。
