# 推荐页沉浸式海报改版设计

日期：2026-09-18

## 背景与问题

现有推荐页已经具备 Three.js 模型、内容分类和二维降级，但实际预览暴露出三个核心问题：

1. 信息区处于正常文档流，先于舞台占据大量高度，3D Canvas 被推到首屏下方。用户首先看到的是文字，因此无法发现模型和拖动入口。
2. 十一项内容中只有一项使用图片，另外十项使用黑底白字生成封面。技术上纹理已加载，但视觉上仍像纯文字占位，不符合“作品封面”的预期。
3. “全部”分类让首屏同时混入 CD 和书籍，削弱了系列感；现有移动端舞台与信息区也没有形成参考图中的沉浸式海报构图。

本次改版不推翻内容层和模型注册表，只重新定义页面构图、默认筛选、封面来源契约以及无 WebGL 时的交互降级。

## 已确认的目标

- 采用 A 方案：沉浸式海报舞台，白底黑字，物体占据首屏主体。
- 桌面端标题、作者和年份位于左上角；不展示推荐语。
- 删除“全部”，默认进入“音乐”。
- 当前作品只支持拖动旋转；不自动旋转、不缩放、不平移相机、不打开书或翻页。
- 使用官方或权威封面 CDN，不把第三方封面文件重新分发进仓库。
- WebGL 不可用时仍提供可拖动的 CSS 立体 CD / 书籍，而不是黑白封面列表。
- 保持内容类型、作品类型和视觉模型低耦合，未来可以独立增加分类、封面来源或模型。

## 非目标

- 不增加播放音乐、预告片、收藏、评分或用户账号。
- 不引入服务端图片代理、图片下载任务或密钥管理。
- 不为书籍增加翻页、开合、骨骼或物理模拟。
- 不改变博客、随笔、项目与关于页面的视觉系统。

## 页面构图

### 桌面端

推荐页主体使用一个接近视口高度的海报区域：

- 顶部为精简站点导航，下面直接进入海报舞台。
- 左上角信息块按顺序显示分类、标题、作者和年份；标题使用大号衬线字，但宽度受限，避免覆盖当前模型。
- 右上角显示三个分类入口：音乐、书籍、影视与动画。音乐默认选中，不存在“全部”。
- 中间与右侧是单个全宽 3D Canvas。当前作品处于视觉中心，两侧各露出一至两个邻居，形成参考图中的交错实物构图。
- 右下角显示序号和简短的 `Drag to rotate` 提示。
- 上一项和下一项使用舞台边缘箭头，不再占据整行导航条。
- 来源、许可与作品详情放入海报底部细栏，视觉权重低于标题和模型。

信息和舞台共享同一海报容器，通过 CSS Grid 叠放，而不是依次进入文档流。Canvas 必须在首屏内可见且可命中。

### 移动端

- 海报区域先展示约 55–60svh 的舞台，当前作品居中，两侧仅露出相邻作品边缘。
- 标题、作者和年份位于舞台左上安全区，使用较小字号和半透明纸色底，避免与封面冲突。
- 分类入口横向排列；文本仍完整显示，不恢复“全部”。
- 来源与详情位于舞台之后，页面保持纵向滚动且无横向溢出。

### 首页精选

首页继续只取三项精选，但使用同一视觉语言的紧凑海报区。它不显示完整分类导航，只保留当前作品、邻居、基本信息和“查看全部推荐”。

## 内容与类型契约

### 删除推荐语

`summary` 从推荐内容中彻底删除：

- 删除 `RecommendationItem.summary`。
- 删除 recommendations collection schema 中的 `summary`。
- 删除十一份 Markdown 的 `summary` 字段。
- 页面、首页精选、WebGL 舞台和 CSS 降级组件均不接收或渲染推荐语。
- 严格 schema 继续拒绝未知字段，因此遗留 `summary` 会使内容测试失败。

### 封面判别联合

封面数据改为三种明确来源：

```ts
type RecommendationCover =
  | { kind: 'generated'; credit: string }
  | {
      kind: 'licensed';
      src: string;
      sourceUrl: string;
      license: string;
      licenseUrl: string;
      credit: string;
    }
  | {
      kind: 'remote';
      src: string;
      sourceUrl: string;
      provider: 'cover-art-archive' | 'open-library' | 'tmdb';
      credit: string;
    };
```

- `licensed` 保留给仓库中可明确再分发的本地素材，例如现有 Back in Black 的 PD-textlogo SVG。
- `remote` 只保存 HTTPS CDN 地址、作品来源页、提供方和署名，不下载到仓库。
- `generated` 是网络失败、CORS 失败或无合适远程封面时的最终回退。
- 展示类型 `disc | book` 仍由模型注册表解析，与封面来源无关。

### 远程来源策略

按内容类型使用以下公开、可署名的数据源：

- 音乐：MusicBrainz / Cover Art Archive 的 release 或 release-group front image。它提供稳定 API 和缩略图，但官方文档明确要求使用者自行判断艺术作品权利，因此页面必须显示来源，不宣称图片属于公共领域。
- 书籍：Open Library Covers API。官方指南明确允许公共页面直接使用 `covers.openlibrary.org` 的 `src` URL，并建议链接回 Open Library。
- 影视与动画：TMDB image CDN。仅用于非商业博客并按其 FAQ 添加 TMDB 来源声明；页面不得暗示 TMDB 认可本站。

Apple iTunes Search API 不作为默认来源，因为其宣传素材使用要求与商店徽章、商店内容推广绑定，不适合当前纯推荐页面。

所有远程纹理必须先验证 HTTPS、CORS 和最小尺寸。失败时只对该作品降级为彩色生成封面，不影响 Canvas 或其他作品。

## 状态与数据流

`RecommendationExperience` 继续拥有筛选和当前项状态，但默认筛选从 `all` 改为可配置的 `music`：

1. catalog 模式默认 `music`；有效 URL hash 可以选中其他分类中的项目，并同步切换对应分类。
2. 点击分类时选择该分类第一项。
3. 点击邻居、舞台箭头或方向键只更新当前项，不重建整个页面。
4. WebGL 舞台和 CSS 立体降级接收相同的 `items`、`activeId`、`onSelect` 和拖动边界，不各自拥有筛选状态。
5. 首页 featured 模式不显示分类入口，继续由首页查询决定项目集合。

## 3D 交互

- 当前模型用有限角度的拖动控制器；非当前模型只响应点击选择。
- 水平与垂直旋转都有上限，避免看到不合理的穿模角度。
- 松手后使用阻尼回到作品的初始姿态；减少动态效果时直接复位。
- Canvas 使用按需渲染：拖动、切换和纹理到达时请求帧，静止后停止。
- Canvas 容器使用 `touch-action: pan-y`，横向拖动模型不阻塞页面纵向滚动。
- 不使用 OrbitControls，不暴露缩放、相机平移或自动旋转。

## CSS 立体降级

WebGL 不可用或初始化失败时，降级组件只呈现当前项及少量邻居：

- CD 使用圆形元素、中心孔、边缘厚度和封面背景图构成立体物件。
- 书籍使用封面、纸张块和书脊三个平面构成立体物件。
- Pointer Events 驱动 `rotateX` / `rotateY`，松手阻尼复位；旋转范围与 WebGL 版本一致。
- 远程 `<img>` 加载失败时切换为彩色生成封面。
- 降级不是模型精度替代品，但必须保留“单个实物、可拖动、可切换”的核心体验。

## 错误处理与来源展示

- 远程封面失败：单项使用生成封面，并保留来源链接供用户访问。
- WebGL 能力检测失败或上下文丢失：切换 CSS 立体舞台，当前选择不丢失。
- 空分类：显示简短空状态，不挂载舞台。
- `remote` 封面显示来源提供方；TMDB 相关页面包含其要求的非认可声明。
- 外部详情、封面来源和许可链接均使用安全的新标签页属性。

## 测试与验收

### 单元与组件测试

- schema 拒绝 `summary`，接受严格的 `remote` 封面对象并拒绝非 HTTPS 或额外字段。
- catalog 默认筛选为音乐，界面不存在“全部”。
- hash 指向书籍或影视项目时自动切换到对应分类。
- 远程封面加载失败后使用生成封面。
- CSS 立体舞台在 pointer down / move / up 后更新并复位角度。

### 浏览器测试

- 390×844 和桌面尺寸的首屏中，Canvas 或 CSS 立体舞台可见，标题、作者和年份位于左上角。
- 首屏不存在推荐语，也不存在“全部”按钮。
- 真拖动会改变舞台截图，松手后回到初始姿态，当前作品不会误切换。
- 远程封面在 HTML 与 3D 纹理中可见；故意制造加载失败时出现彩色回退。
- WebGL 被禁用时仍有单项 CSS 立体模型并可拖动。
- 移动端可纵向滚动、无横向溢出，分类入口和来源链接可访问。
- 首页其他区块的视觉与行为不变。

## 风险与取舍

- 远程封面依赖第三方可用性和 CORS；通过本地生成回退保证可读性，但无法保证第三方永远稳定。
- Cover Art Archive 与 TMDB 提供展示接口不等于封面原作进入公共领域。本方案通过远程引用、清晰署名和非商业使用降低风险，不声称消除版权责任。
- CSS 立体降级增加少量交互代码，但避免无 WebGL 设备退回纯文字列表，直接解决本次体验缺口。
