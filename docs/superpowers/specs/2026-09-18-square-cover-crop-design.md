# 推荐作品正方形封面裁剪设计

## 目标

- 将《月亮与六便士》的图片来源替换为 Standard Ebooks 官方仓库中的源封面图。
- 对远程及授权图片统一执行居中正方形裁剪，保持原始宽高比，不拉伸。
- 保持内容配置、裁剪逻辑和 3D 展示模型低耦合。

## 内容来源

《月亮与六便士》使用 Standard Ebooks 官方仓库的 `images/cover.jpg`。内容配置保存图片 URL、仓库来源 URL、提供方和署名；图片本身不提交到仓库。Standard Ebooks 声明原作文本与艺术作品在美国属于公共领域，项目贡献以 CC0 贡献至公共领域。

## 显示规则

### WebGL

纹理加载成功后根据原图尺寸计算 UV：

- 竖图保留完整宽度，垂直居中裁去上下多余区域；
- 横图保留完整高度，水平居中裁去左右多余区域；
- 正方形图片保持原样。

CD 使用裁剪后的正方形纹理覆盖圆形表面。书籍保持竖向实体外形，但封面图片使用正方形平面居中放置，剩余区域显示书封底色。

### CSS 回退

CD 和书籍图片均使用 `object-fit: cover` 居中裁剪。书籍封面图片保持 `aspect-ratio: 1` 并垂直居中，剩余区域显示书封底色。生成封面沿用相同正方形容器。

## 边界与错误处理

- 图片加载失败时继续回退到现有的原创生成封面。
- 图片尺寸不可用时不修改 UV，避免产生无效纹理参数。
- 不引入新的图片处理依赖，也不下载或提交第三方图片。

## 测试与验收

- 为纯函数覆盖横图、竖图、正方形和无效尺寸。
- 验证远程图片仍配置为 sRGB，失败回退和销毁行为不变。
- 验证《月亮与六便士》使用新的 Standard Ebooks 来源与署名。
- 在真实浏览器中检查书籍与唱片图片均无拉伸，CSS 回退与 WebGL 一致。
